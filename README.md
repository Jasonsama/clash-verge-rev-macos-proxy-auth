## Install

请到发布页面下载对应的安装包：[Release page](https://github.com/Jasonsama/clash-verge-rev-macos-proxy-auth/releases)<br>
Go to the [Release page](https://github.com/Jasonsama/clash-verge-rev-macos-proxy-auth/releases) to download the corresponding installation package<br>
Supports Windows (x64/x86), Linux (x64/arm64) and macOS 11+ (intel/apple).


```shell
pnpm i
pnpm run prebuild
pnpm dev
```
